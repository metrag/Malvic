**1. Open-Source проекты на базе ESP32 (максимально близкие по железу):**
- **Xiaozhi AI (小智 AI Chatbot на ESP32-S3):** Один из самых популярных сейчас открытых проектов в сообществе мейкеров. Использует практически идентичный твоему стек: **ESP32-S3 + INMP441 (аналог твоего MS3625) + MAX98357A + SSD1306 OLED**. В нем уже идеально отлажен двусторонний аудио-стриминг по WebSocket, локальный Wake Word, работа с LLM и вывод эмоций на экран. Его код на GitHub — лучшая отправная точка для написания сетевого и аудио-слоя прошивки.
    
- **DeskMate (ESP32-S3 + OLED + MPU6050):** Свежий DIY-проект настольного компаньона, где основной упор сделан на связку OLED-глаз и гироскопа MPU6050 — глаза следят за наклонами корпуса, а встряхивание переключает эмоциональные состояния.
    
- **FluxGarage RoboEyes / Desktop Companion Robot:** Серия проектов на базе библиотеки `RoboEyes` для SSD1306. Вместо хранения тяжелых растровых спрайтов во флеш-памяти, библиотека рисует глаза геометрическими примитивами на лету (с поддержкой моргания, прищура, удивления, тряски и взгляда в заданные координаты).
